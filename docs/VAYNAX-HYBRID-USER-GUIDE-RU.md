# MATRIX VPN 0.6.0 — инструкция пользователя (RU)

## Что есть в этой сборке

- Отдельная кнопка **«WARP — отдельный режим»**. MATRIX запрашивает WARP-совместимый WireGuard/AWG профиль у стороннего генератора и сохраняет его как профиль WARP. Это не официальный клиент Cloudflare и не официальный API Cloudflare.
- Импорт WireGuard/AmneziaWG из файла телефона или буфера обмена.
- Зашифрованный пул до 40 WireGuard/AmneziaWG профилей. Секретная конфигурация шифруется AES-GCM с ключом Android Keystore; профиль можно выбрать, удалить и восстановить после перезапуска.
- Каталог VPN Gate. Его список содержит профили OpenVPN. Пока встроенный MATRIX не подключает OpenVPN напрямую: файл передаётся установленному совместимому OpenVPN-приложению.
- Локальная оценка сохранённых профилей по фактическим результатам HTTPS-проверок и времени ответа.
- Последовательная попытка резервного профиля при провале первичной HTTPS-проверки. Она допускается только когда для MATRIX включены Android Always-on VPN и «Блокировать подключения без VPN». Это не бесшовное переключение и не постоянный фоновый мониторинг работающего туннеля.

## Первое подключение

1. Установите APK и откройте MATRIX.
2. Для отдельного WARP-режима нажмите «WARP — отдельный режим». Дождитесь загрузки профиля и системного запроса Android на разрешение VPN.
3. Для своего WireGuard/AmneziaWG профиля нажмите «Импорт файла» или «Импорт из буфера телефона».
4. Подтвердите запрос Android на создание VPN-соединения.
5. Нажмите «Мои профили • умный выбор», чтобы посмотреть сохранённые профили, их оценку, выбрать другой профиль или удалить ненужный.
6. Для резервной проверки откройте «Резервное восстановление» и перейдите в настройки Android VPN. Включите для MATRIX «Постоянная VPN» и «Блокировать подключения без VPN», если эти параметры доступны в прошивке.

## Безопасность и ограничения

- Не импортируйте неизвестные конфигурации и не передавайте приватные ключи. Оператор VPN-сервера может наблюдать часть метаданных и незашифрованный трафик.
- Успешная HTTPS-проверка показывает доступность внешнего сайта через выбранный путь, но не заменяет криптографическую проверку WireGuard peer-handshake.
- WARP-генератор сторонний; его доступность, профили и реальное подключение не гарантируются.
- VPN Gate — добровольческие серверы. Для их OpenVPN-профилей нужен внешний OpenVPN-клиент. MATRIX не выдаёт такой узел за встроенный WARP/WireGuard.
- Автоматическое резервное восстановление в этой версии работает только при первичном неуспешном подключении и подтверждённой Android lockdown-настройке. Нет гарантии бесшовного переключения, фонового переключения при позднем обрыве или нулевых утечек без испытаний на устройстве.
- Реальная проверка на Android 15, включая DNS/IPv6 и сетевую смену Wi-Fi/мобильной сети, ещё необходима.

Начальная целевая модель проверки: Realme Note 50, Android 15. Поддержка Android 13–16 пока является целью совместимости, а не результатом испытаний.
